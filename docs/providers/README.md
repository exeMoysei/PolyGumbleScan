# Провайдеры

Для каждого источника перед подключением выполняется probe (`polybot probe`): доступ, квоты, частота
обновления, права на использование и передачу данных, правила, стабильность ID, полнота лимитов и
пересечение с действующими источниками. Площадки без подходящей линии на внешнее событие в расчёт не входят.

| Провайдер | Файл | Статус адаптера | Live probe |
|---|---|---|---|
| Polymarket | [polymarket.md](polymarket.md) | готов (REST + опц. WebSocket) | ⏳ на VPS (из dev-среды заблокировано) |
| Kalshi | [kalshi.md](kalshi.md) | готов (REST) | ⏳ на VPS |
| The Odds API | [the-odds-api.md](the-odds-api.md) | готов (REST) | ⏳ на VPS, нужен ключ |
